# E.V.E. Verification Guide

E.V.E. independently verifies material execution results. This package
supports E.V.E. verification through:

1. `evidence.assertEvidenceChain` — verifies tamper-evident chain of
   custody for evidence.
2. `evidence.verifyHash` — verifies payload hashes.
3. `observability.assertNoSilentFailures` — verifies no silent failures.
4. `evidence/RUNTIME_VERIFICATION.md` — produced by `npm run verify`,
   enumerates every step's pass/fail status.

# Category Mapping

**Package:** primeopp-marketplace-platform

**Last updated:** 2026-01-01

## Overview

Category mappings translate canonical categories to marketplace-specific categories with required/optional/prohibited attributes and confidence scores.

## Default Mappings

- sneakers → sneakers (confidence 0.95)
- apparel → clothing (0.9)
- electronics → electronics (0.9)
- books → books (0.95)
- collectibles → collectibles (0.8, human confirmation required)
- video_games → video_games (0.92)

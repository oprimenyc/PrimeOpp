# Local Pickup

**Package:** primeopp-marketplace-platform

**Last updated:** 2026-01-01

## Features

- Pickup eligibility
- Pickup location reference
- Safe meeting policy
- Store pickup
- Appointment window
- Pickup code
- Buyer + seller confirmation
- Timeout, no-show, cancellation
- Completion evidence

## Privacy

No private home addresses exposed without explicit seller policy. Public/business location policies supported.
